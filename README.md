# TalentExchange - Web App Full Stack

Progetto realizzato per il corso di Tecnologie Web presso l'Università degli Studi di Torino. L'applicazione è una piattaforma web basata su un'architettura client-server disaccoppiata.

# Stack Tecnologico
Backend: Sviluppato in Java Spring Boot, utilizzando JPA/Hibernate per la gestione della persistenza dei dati.
Frontend: Single Page Application (SPA) realizzata con React.js garantendo un'interfaccia utente dinamica e reattiva.
Database: MySQL per la gestione relazionale dei dati.
UI/UX Design responsive implementato con Bootstrap.

# Funzionalità e Architettura
API RESTful: Il frontend comunica con il backend tramite endpoint REST.
Gestione Stato: Utilizzo di componenti React per una gestione fluida del flusso di dati lato client.
